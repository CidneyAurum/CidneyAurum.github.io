还没有选择图片

支持 JPG、PNG、WebP 和 GIF，每张不超过 20MB。令牌上传会添加唯一编号，避免覆盖同名照片；失败后队列保留尚未完成的图片。免令牌方式需在 GitHub 上传页完成提交；照片墙在 Pages 部署完成后更新。

创建方法：GitHub → Settings → Fine-grained tokens → Repository access 选「Only select repositories」并选择 CidneyAurum/CidneyAurum.github.io → Permissions 里给 Contents: Read and write → 生成后复制粘贴到这里。
安全说明：令牌只保存在你当前浏览器的 localStorage，只发往 api.github.com；建议设置较短的过期时间，不用时点「清除令牌」。
