## 本轮首页演出待验证范围

本轮将演出直接接入首页音乐区，删除旧独立实验室页面及入口。设计行为参考 [星梦幽灵的小窝](https://xmyl-153.github.io/xingmengyouling-blog/) 与 [桌面歌词演出项目](https://github.com/YouRanCoder/LimbusLyricSimulator)，没有复制 GPL-3.0 桌面实现。

- 原生音频实际播放与进度推进时，舞台歌词、时间和当前歌曲一致；同时间戳原文/译文正确配对。
- 暂停后保持当前时间，恢复后续接；seek、回拖与切歌清理过期残影，迟到歌词不会覆盖新歌。
- 逐字入场、残影和斩击随句切换；关闭动效或系统 reduced motion 时歌词仍可完整阅读。
- 紧凑与沉浸模式共用播放状态；收起后音乐继续，手机无横向溢出，关闭可恢复焦点。
- 加载中、无歌词和失败状态明确；重试只重新读取当前歌词，不意外重播或切歌。
- 导航、文章模板、知识索引和发布产物不再提供旧实验室入口。

## 既有修复基线

- 播放器：修复切歌竞态、拒绝播放却显示播放中、旧歌词/旧恢复进度覆盖新歌曲、无限跳过失败曲目、双重空格事件和拖动取消状态。失效候选有超时与有限尝试，切歌只滚动歌单。
- 写作台：修复不安全的预览插值、元数据引号与换行丢失、读取失败继续写入、无提示覆盖、说说并发覆盖、图片预览与失败队列。保存文字草稿，离开未上传图片时提醒。
- 发布反馈：只有对应提交的 `github-pages` 部署成功才显示已上线；提交成功或其他工作流成功不作上线证明。
- 看板娘：补齐无 Key 本地回复、自定义音乐 API 设置、协议地址规范化、请求超时、中文输入法保护、并发发送与模型失败重试。
- 站内 AI：公开内容索引、文章上下文与引用校验、取消/重试、导航与点歌建议、写作提案应用/撤销已实现并上线。公网全站每日 100 次额度已生效；知识索引按 60 秒 TTL 在线刷新，日常内容更新无需本机重启或部署 Worker。
- 内容与浏览：评论区域纳入换页范围；列表读取有超时和重试；修复时间轴装饰遮挡按钮，以及浏览器跳过过渡动画时未处理的 Promise 拒绝。
