## 本轮修复

- 播放器：修复切歌竞态、拒绝播放却显示播放中、旧歌词/旧恢复进度覆盖新歌曲、无限跳过失败曲目、双重空格事件和拖动取消状态。失效候选有超时与有限尝试，切歌只滚动歌单。
- 写作台：修复不安全的预览插值、元数据引号与换行丢失、读取失败继续写入、无提示覆盖、说说并发覆盖、图片预览与失败队列。保存文字草稿，离开未上传图片时提醒。
- 发布反馈：只有对应提交的 `github-pages` 部署成功才显示已上线；提交成功或其他工作流成功不作上线证明。
- 看板娘：补齐无 Key 本地回复、自定义音乐 API 设置、协议地址规范化、请求超时、中文输入法保护、并发发送与模型失败重试。
- 站内 AI：公开内容索引、文章上下文与引用校验、取消/重试、导航与点歌建议、写作提案应用/撤销已实现并上线。公网全站每日 100 次额度已生效；知识索引按 60 秒 TTL 在线刷新，日常内容更新无需本机重启或部署 Worker。
- 内容与浏览：评论区域纳入换页范围；列表读取有超时和重试；修复时间轴装饰遮挡按钮，以及浏览器跳过过渡动画时未处理的 Promise 拒绝。
- 模拟器：修复谢幕与旧歌词重叠、重置后同步事件重新绘字，以及回拖至第一句前仍显示未来歌词。

## 自动检查

本次发布 CI：**70 项 Node、116 项 Python/Chromium 检查，合计 186 项通过**，[Actions](https://github.com/CidneyAurum/CidneyAurum.github.io/actions/runs/40171647787) 的 build/deploy 均成功。覆盖原有功能、公开知识索引、在线同步、AI 侧栏、写作草稿保护、看板娘接入，以及服务端校验、预算和错误处理。回归失败会阻止后续上传与部署。陪伴功能说明见 [陪伴体验](miku-companion.md)。

```bash
python -m pip install -r requirements-build.txt -r requirements-test.txt
python -m playwright install chromium
node --test tests/*.test.cjs tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py' -v
```

浏览器回归测试会启动独立的临时本地服务器与新浏览器上下文，业务 API 使用隔离夹具，GitHub 写入全部模拟；离线套件使用真实 Service Worker，音频套件使用真实浏览器解码的本地 WAV。真实公共音乐与 Live2D 的检查另行进行，不混算为模拟接口可用的证据。

真实公网 Worker POST 返回 HTTP 200，status 为 configured=true，回答包含 1 条有效引用。正式域名浏览器随后完成文章总结与引用、手机侧栏边界、写作标题应用及撤销检查；本机请求数、浏览器直连模型供应商数、网关请求鉴权头数和 GitHub 写入数均为 0，脚本错误列表为空。本机 8000/8787 服务已停止，本轮 DPAPI 凭据文件已删除，模型凭据由 Cloudflare Secret 托管。此前本机 API 和原生 SQLite 预算验证保留为补充证据。
