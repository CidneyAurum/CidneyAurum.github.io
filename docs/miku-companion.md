# Miku 的陪伴体验

首页的「初音的值班室」把语音、模型、导览与真实播放器接在一起。点击后才加载 Live2D；页面打开时不自动说话。

## 怎么玩

- **听听初音**：试听五段日语角色短句，有日中字幕、来源和静音按钮。AI 的长回复保留文字。
- **带我逛逛**：Miku 依次指出最新手记、光影收藏、最近的日常，能直接打开对应内容；到相册或文章页后也能继续找图、挑手记。
- **一起听歌**：进入「耳机分你一半」小房间；闲置时先播放音乐开场短句，再启动真实歌单。可以暂停、切歌、看实际歌词；关掉房间后音乐继续播放。
- **比个心或轻点模型**：触发实际比心表情与亲近回应。拖动模型不会误触点击反应。听歌时不会自动用短语音打断歌曲。

语音来自《Project SEKAI》初音角色介绍中的现成短句，五个 WAV 保持原音高。声音不经过浏览器系统朗读或在线 TTS。口型仅跟随角色音频的实际幅度；歌曲播放时使用模型的唱歌表情，不把随机嘴动称为音频口型同步。

## 维护位置

| 内容 | 位置 |
| --- | --- |
| 首页入口 | `index.html` 的 `#miku-host` |
| 导览、听歌房、试听卡与跨页陪伴 | `js/miku-host.js` |
| 角色短语音、字幕、音频幅度与静音 | `js/miku-voice.js` |
| 模型、表情、聊天与设置桥接 | `js/kanban.js` |
| 全站延迟加载入口 | `js/garden.js` |
| 值班室、浮动卡片与弹窗样式 | `css/miku-host.css` |
| 原始音频、台词与来源 | `assets/voice/miku/manifest.json`、`assets/voice/miku/CREDITS.md` |

新增短句需要同时维护音频与清单。语音失败会保留文字和重试入口，不回退到系统声音。源码中的临时表情只使用现有七个模型预设；不要假设模型含有未提供的跳舞、挥手等动作。

原始音频权利保留，不能把游戏语音声明成本站的开源语音包。当前接入用于本地个人站点评审，音频来源和权利说明随素材保留；本次未推送或公开发布。

## 验证

`tests/test_miku_voice.py` 使用真实 WAV 和原生浏览器，验证播放、实际音频幅度、互斥、中止、静音、失败重试及完全不调用系统 TTS。`tests/test_miku_host.py` 验证真实内容导览、听歌房状态、关闭与异步开场竞态、字幕、手机布局和焦点恢复。`tests/test_kanban.py` 验证模型桥接、表情恢复及远程 AI 回复静音。

另已独立验证实际 CDN 模型、日语短句、真实在线歌曲共同运行：原生播放时有非零音频幅度，模型画布存在，听歌房关闭后歌曲继续、模型回到页面，390px 页面无横向溢出。
