# Miku 的陪伴体验

最新可见性修复与正式站实模验收见 [Miku 可见性修复](miku-visibility-fix.md)。右侧入口现在持续提供「叫回 Miku」，人物与聊天采用独立定位，完整位置边界与陪伴卡遮挡已有回归覆盖。

首页的「初音的值班室」把语音、模型、导览与真实播放器接在一起。点击后才加载 Live2D；页面打开时不自动说话。

## 怎么玩

- **听听初音**：试听五段日语角色短句，有日中字幕、来源和静音按钮。AI 的长回复保留文字。
- **带我逛逛**：Miku 依次指出最新手记、光影收藏、最近的日常，能直接打开对应内容；到相册或文章页后也能继续找图、挑手记。
- **一起听歌**：进入「耳机分你一半」听歌房；闲置时先播放音乐开场短句，再启动真实歌单。首页选歌、Miku 点歌和听歌房共享 MikuMusic；整页背景歌词接入同一真实音频时钟，由首页音乐卡「背景演出」或全局播放器「演」专用开关控制。暂停、切歌和拖动进度同步更新歌词，关掉房间后音乐继续。
- **比个心或轻点模型**：触发实际比心表情与亲近回应。拖动模型不会误触点击反应。听歌时不会自动用短语音打断歌曲。

语音来自《Project SEKAI》初音角色介绍中的现成短句，五个 WAV 保持原音高。声音不经过浏览器系统朗读或在线 TTS。口型仅跟随角色音频的实际幅度；歌曲播放时使用模型的唱歌表情，不把随机嘴动称为音频口型同步。

## 整页背景歌词

本轮将歌词重做为 body 直属的透明背景层，fixed 覆盖整个视口且不占布局。鼠标与触摸穿透该层，前景卡片、导航、按钮和播放器正常操作，页面正常滚动。15 项背景回归、210 项全套 CI、Pages 发布与正式域名真实歌曲背景演出验收均已通过。

歌词随歌曲默认启用，首页音乐卡「背景演出」和全局播放器「演」是同一效果的专用开关；原「词」按钮只展开或收起可点击跳播的歌词列表，两个开关独立。关闭背景不会暂停歌曲。它与 MikuMusic 共用真实时钟，暂停、恢复、seek、回拖、切歌和同时间戳双语继续同步；切歌或无歌词时清理旧句。

每句激活后保持稳定的散落位置和约 ±10° 基线。字形正立、沿倾斜基线排布，以至少 30ms/字逐字揭示，并伴随轻微抖动。CJK 为粗黑字形与金色偏移阴影，英文使用描边。旧句保留原位置和角度，约 660ms 内上浮约 22px 并淡出。系统 reduced motion 偏好降低动态效果，手机长句保持在视口内。

日语角色短句只用于陪伴互动，歌曲歌词来自当前音乐数据。布局参考 [星梦幽灵的小窝](https://xmyl-153.github.io/xingmengyouling-blog/)，歌词行为对照桌面项目的 [歌词窗口](https://github.com/YouRanCoder/LimbusLyricSimulator/blob/main/ui/lyric_window.py) 与 [逐字及残影绘制](https://github.com/YouRanCoder/LimbusLyricSimulator/blob/main/ui/fading_line.py)。本站独立实现 Web 版本，没有复制 GPL-3.0 桌面项目代码。

## 维护位置

| 内容 | 位置 |
| --- | --- |
| 首页入口 | index.html 的 #miku-host |
| 导览、听歌房、试听卡与跨页陪伴 | js/miku-host.js |
| body 背景节点、专用开关、真实时钟同步、双语、散落位置与残影清理 | js/lyric-stage.js |
| 透明层、穿透层级、正立字形、倾斜基线、残影与减弱动效 | css/lyric-stage.css |
| 当前歌曲、真实音频时钟、歌词数据、全局按钮与原歌词列表 | js/music.js |
| 角色短语音、字幕、音频幅度与静音 | js/miku-voice.js |
| 模型、表情、聊天与设置桥接 | js/kanban.js |
| 全站延迟加载入口 | js/garden.js |
| 值班室、浮动卡片与弹窗样式 | css/miku-host.css |
| 原始音频、台词与来源 | assets/voice/miku/manifest.json、assets/voice/miku/CREDITS.md |

新增短句需要同时维护音频与清单。语音失败会保留文字和重试入口，不回退到系统声音。源码中的临时表情只使用现有七个模型预设；不要假设模型含有未提供的跳舞、挥手等动作。

原始音频权利保留，不能把游戏语音声明成本站的开源语音包。语音资源已随既有站点发布，来源和权利说明随素材保留。
