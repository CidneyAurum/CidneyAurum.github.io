# 界面维护说明

站点布局参考 [星梦幽灵的小窝](https://xmyl-153.github.io/xingmengyouling-blog/) 的模糊背景、玻璃卡片、资料与音乐双栏及拼贴内容区域。歌词本轮改为覆盖整个视口的透明背景层，直接对照桌面项目的 [歌词窗口](https://github.com/YouRanCoder/LimbusLyricSimulator/blob/main/ui/lyric_window.py) 与 [逐字及残影绘制](https://github.com/YouRanCoder/LimbusLyricSimulator/blob/main/ui/fading_line.py) 的真实设计行为。

本站使用独立的 HTML/CSS/JavaScript 实现，没有复制 GPL-3.0 桌面项目代码；相关致谢保留在 README。个人资料、文章、相册、说说与歌单仍来自本站内容。本轮 210 项 CI、Pages 发布与正式域名《勾指起誓》真实歌曲背景演出验收均已通过。

## 整页透明背景歌词

歌词层是 body 的直属节点，使用 fixed 透明覆盖全视口且不占文档布局。歌词可以出现在内容区域上方，鼠标与触摸穿透该层；前景卡片、导航、播放器与按钮保持可点击，滚动和键盘焦点按原页面工作。无需打开额外歌词面板。

歌词默认随歌曲启用，首页音乐卡「背景演出」和全局播放器「演」专门控制这一背景效果；原「词」按钮控制可点击跳播的歌词列表，二者独立。歌词层与首页、底部播放条和听歌房共用 MikuMusic 的同一音频和真实时钟。同时间戳原文与译文成组显示；暂停、恢复、seek、回拖、循环归零与切歌均根据当前音频时间重新定位。切歌、无歌词、失败与迟到响应不能留下或覆盖错误歌曲的句子。

每句根据歌曲与时间戳生成稳定随机位置和约 ±10° 倾斜基线，从最多 12 个候选落点中避开残影；每个字形反向旋转保持正立，字的位置沿基线变化。逐字揭示的间隔至少为 30ms，并加入轻微抖动。CJK 使用粗黑字形与金色偏移阴影，英文使用描边。旧句保留原来的位置与角度，约 660ms 内上浮约 22px 并淡出，不积累为长期词云。

系统 reduced motion 偏好降低抖动和位移动画，歌词保持可读。手机长句需要在视口内换行和限制散落边界，原文与译文不能互相覆盖。独立实验室页面和导航入口已移除；本轮不恢复独立入口。

## 修改位置

| 内容 | 文件 |
| --- | --- |
| 首页资料、音乐卡与内容布局 | index.html |
| body 直属背景节点、专用开关、时间同步、双语分组、随机位置与残影生命周期 | js/lyric-stage.js |
| fixed 全视口透明层、穿透与层级、正立字形、倾斜基线、手机与 reduced motion | css/lyric-stage.css |
| 当前歌曲、时间轴歌词、真实音频时钟、全局按钮与原歌词列表 | js/music.js |
| 全站视觉、深浅主题和手机布局 | css/garden.css |
| 图标、主题卡、首页数据与组件延迟加载 | js/garden.js |
| Miku 值班室、听歌房与日语角色短句 | js/miku-host.js、js/miku-voice.js、css/miku-host.css |
| 文章源稿与模板 | _posts/*.md、tools/build.py 的 POST_TEMPLATE |
| 收藏图片、背景与来源 | assets/gallery/、assets/night-sky.webp、assets/CREDITS.md |

css/style.css 保留播放器、写作台等基础组件样式，garden.css 统一外观；背景歌词样式独立维护。PJAX 换页需要处理 body 根节点、订阅与动画的生命周期，防止重复挂载；重新接入时应直接读取当前播放状态。

## 图片、性能与验证

- 夜景素材与页脚署名见 assets/CREDITS.md；首页收藏图复用本站已有资源。
- Live2D 按需加载；歌单封面仅按可视行加载，避免批量请求争用音频所在域的连接。播放/暂停只更新现有状态，不重建 107 条歌单节点。
- 背景歌词每句激活时计算稳定位置，不逐帧随机位置；帧级更新只处理必要的揭示、抖动与淡出状态。
- 背景歌词 15 项浏览器用例全部通过，使用真实 HTMLAudio 解码生成的 WAV，并经实际播放、seek 和循环驱动歌词。新增小数延迟用例以 17 字、5.75 秒间隔自然播放，确认末字延迟前隐藏、2.05 秒时全字可见；浏览器内恢复旧 CSS 时能重现后 7 字永久隐藏。
- 修复后的本机页面另以真实公共《勾指起誓》抽样通过：原生时长 183.536771 秒、35 行 LRC，逐字从 1 字增至 17 字完整显示；透明穿透、暂停/背景开关及 PJAX 同一音频均通过，无页面错误、音乐相关失败请求或额外付费 AI 调用。
- 正式域名再次使用真实《勾指起誓》验证上述逐字揭示与交互，音乐和背景脚本实际版本为 2012e8c2d3f9。1440×1000 视口的 body 直属透明层覆盖整页、pointer-events=none，21.92 秒当前句与 27.67 秒下一句分别落在不同位置，旧句保留原位进行 bg-lyric-fade；页面错误、音乐相关失败请求、付费 AI 与本机 API 请求均为 0。
- 独立浏览器验收确认自然换句随机落点、原位残影上浮淡出与连续轻抖；长双语歌词在 320×480、320×568、375×667、390×844 与 844×390 视口内无字框越界；点击和滚动穿透、PJAX 后同一背景层/音频及唯一订阅均通过。
- 背景效果仅尊重新的 lyric_background_effects 设置及系统 reduced motion；旧面板 lyric_stage_effects=0 不会关闭新背景动效，该迁移行为已有回归覆盖。
