🖥️ 桌面版 · LimbusLyricSimulator

  • 读取系统正在播放的音乐，自动获取播放进度
  • 多行歌词同时演出，中英文渲染模式动态切换
  • 基于 PyQt-Fluent-Widgets 的 Fluent 风格控制面板
  • 最小化到托盘、开机自启动、伴奏/Inst 过滤
  • Windows 桌面歌词 overlay，全屏无边框窗口可用

★ GitHub 仓库

🌐 网页版 · 本页功能

  • 三种演出模式：手动推进 / 定时自动 / 本地音乐 + LRC 同步
  • 逐字从两侧飞入、撞击震屏、红色斩击特效
  • 纯前端实现，歌词与音频都不会上传到任何服务器
  • 移动端可用，收藏到主屏幕即可随时开演
