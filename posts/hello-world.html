网站上线啦！🎉

🗓 2026-08-29 # 日常

撒花！✧(≖ ◡ ≖✿) 我的个人小站终于上线了！这是本站的第一篇博客，趁这个机会记录一下小站是怎么搭起来的。

这个网站有什么？

  • 个人主页：自我介绍、最新文章、运行状态，还有流萤粒子背景
  • 博客：就是你现在看到的这个板块，带搜索和标签筛选
  • Limbus 歌词演出模拟器：网页版歌词演出工具，粘贴歌词就能逐句开演，支持本地音乐同步
  • 夜间 / 日间模式：右上角的按钮可以切换

用了什么技术？

整个网站是纯 HTML / CSS / JavaScript 手写的，没有用任何框架和构建工具，所以：

  • 改完代码 git push 一下就自动上线，特别省心
  • 托管在 GitHub Pages，免费
  • 流萤粒子、打字横幅、时钟条、歌词演出引擎都是自己写的百来行小代码
小提示：歌词模拟器的灵感来自 Tempura3 的开源项目和 YouRanCoder 的桌面版重构，详见模拟器页面底部的致谢。

接下来想做什么？

把占位的头像和文章换成真实内容，然后保持每周更新一篇博客（先立个 flag 好了 🚩）。

如果你也在做自己的小站，欢迎参考我的仓库，一起玩呀～
