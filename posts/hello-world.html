《网站上线啦！》

🗓 2026-08-29 📝 约 320 字 · 1 分钟 👁 … 次围观 # 日常

撒花！✧(≖ ◡ ≖✿) 我的个人小站终于上线了！这是本站的第一篇博客，趁这个机会记录一下小站是怎么搭起来的。

这个网站有什么？

  • 个人主页：资料卡、环境电台、最新文章、运行状态，还有流萤和像素猫
  • 拾光档案：博客归档，带搜索，还有时间轴 / 网格双视图
  • 光影画廊：拍立得风格的照片墙
  • Limbus 歌词演出模拟器：网页版歌词演出工具，粘贴歌词就能逐句开演

用了什么技术？

整个网站是纯 HTML / CSS / JavaScript 手写的，没有用任何框架和构建工具，所以：

  • 改完代码 git push 一下就自动上线，特别省心
  • 托管在 GitHub Pages，免费
  • 背景氛围、流萤粒子、时钟条、歌词演出引擎、环境电台（Web Audio 合成音乐）都是自己写的
小提示：右下角有一只像素猫在陪你逛站；点首页的「播放电台」真的会有音乐哦。

接下来想做什么？

把占位的内容换成真实内容，然后保持每周更新一篇博客（先立个 flag 好了 🚩）。

如果你也在做自己的小站，欢迎参考我的仓库，一起玩呀～
