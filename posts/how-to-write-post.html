如何发布一篇新文章 📝

🗓 2026-08-29 # 指南

这个博客没有后台、没有数据库，发文就是「新建一个 HTML 文件 + 在目录里登记一行」，三步搞定。

第 1 步：复制文章模板

把 posts/hello-world.html 复制一份，文件名用英文（这就是文章的 slug），比如 my-first-note.html。文件里的标题、日期、正文改成你自己的，注意里面所有的 ../ 路径都不要动。

第 2 步：在目录里登记

打开 posts/posts.json，往 posts 数组里加一条（注意 JSON 的逗号）：

{
  "slug": "my-first-note",
  "title": "文章标题",
  "date": "2026-09-01",
  "tags": ["日常", "笔记"],
  "emoji": "🪐",
  "summary": "显示在博客列表里的一句话摘要"
}
  • slug 要和文件名一致（不带 .html）
  • date 用 YYYY-MM-DD 格式，列表会自动按日期排序
  • emoji 是列表封面的表情，不填会自动随机分配
  • tags 随便写，列表页会自动生成标签筛选

第 3 步：发布

git add posts/
git commit -m "发布新文章：xxx"
git push

推送后 GitHub Pages 会自动部署，一两分钟内线上就能看到新文章了。

写正文的常用格式

正文写在 <div class="prose"> 里面，所有排版样式都配好了：

  • 小标题用 <h2> / <h3>
  • 行内代码用 <code>，代码块用 <pre><code>
  • 引用用 <blockquote>，图片放 ../assets/ 里再引用
进阶玩法：如果觉得手写 HTML 麻烦，可以用 ChatGPT / ZCode 这类 AI 帮你把 Markdown 转成 HTML 片段，粘进来就行。
